# Stage 15 — experimental database isolation
Transaction-local character context is set in chat, MCP and character dashboard paths. Optional MULTI_RLS_ENABLED=true installs restrictive RLS policies on five multi data tables, with FORCE and a role bypass check. Existing legacy tables and registry tables are unchanged. Do not enable in production before real PostgreSQL integration tests. Turning off the flag does not remove installed policies. The runtime role must not have BYPASSRLS or superuser; a separate migration/runtime role is recommended. No persistent extraction queue or concurrent deduplication is implemented. Network calls inside tenant transactions may hold connections for extended periods. Tests use mocks, not PostgreSQL. No real client or Neon tests.
