# Stage 16 — experimental durable extraction queue
Chat persistence and enqueue share a tenant transaction. Worker polls every five seconds, claims with SKIP LOCKED, uses a five-minute lease and retries up to five attempts. Job completion and extracted writes share a transaction. RLS includes multi_jobs when enabled. No API keys in jobs. Uses current settings and recent session context at execution, not an immutable snapshot. Disabled extraction skips queued jobs. Worker holds a DB connection during extraction; no global concurrent memory deduplication, job retention, manual retry UI, migration ledger or real PostgreSQL tests yet. Do not deploy to production. Existing legacy path unchanged.
