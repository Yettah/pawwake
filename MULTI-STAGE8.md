# Stage 8 experimental semantic recall
Opt-in via existing MEMORY_VECTOR_ENABLED and explicit EMBEDDING_API_KEY. Uses existing embedding URL/model/dimension settings; sends query and missing memory text to that provider. JSONB vectors scoped by character and embedding profile; cosine scoring in Python, no pgvector index. Up to 500 candidates, 32 new embeddings per request; keyword fallback on retrieval errors. Hybrid weights .55/.45 and semantic threshold .70 are provisional. No automatic consolidation, RLS, live database or client tests. Do not deploy as production. Unit tests use mocks.
